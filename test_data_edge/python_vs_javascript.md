# Python vs JavaScript Comparison

## Syntax Comparison
| Feature | Python | JavaScript |
|---------|--------|------------|
| Typing | Dynamic | Dynamic |
| Lists | `[1, 2, 3]` | `[1, 2, 3]` |
| Dicts | `{"a": 1}` | `{"a": 1}` |
| Functions | `def f():` | `function f() {}` |
| Comments | `# comment` | `// comment` |

## Use Cases
Python: Data science, ML, backends
JavaScript: Frontend, full-stack, mobile

## Performance
V8 JavaScript engine is highly optimized.
Python's numpy uses C under the hood.
