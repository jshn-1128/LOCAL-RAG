# RAG vs Fine-Tuning

## RAG Advantages
- Knowledge updates: Instant (re-index)
- Cost: Low (no training)
- Transparency: Source attribution
- Hallucination: Lower risk

## Fine-Tuning Advantages
- Domain depth: Can learn patterns
- Performance: No retrieval latency
- Offline: No external dependency

## When to Use RAG
- Frequently updated knowledge
- Need source transparency
- Large knowledge base
- Low budget for training

## When to Fine-Tune
- Stable domain knowledge
- Need style/tone control
- High throughput requirements
- Offline deployment
