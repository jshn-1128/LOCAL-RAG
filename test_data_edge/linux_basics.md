# Linux Basics Tutorial

## File Operations
| Command | Description |
|---------|-------------|
| `ls` | List files |
| `cd` | Change directory |
| `pwd` | Print working directory |
| `mkdir` | Create directory |
| `rm` | Remove files |
| `cp` | Copy files |
| `mv` | Move files |

## Permission
```bash
chmod 755 script.sh
chown user:file
```

## Process Management
```bash
ps aux
kill -9 PID
nohup command &
```

Linux is an open-source operating system kernel first released in 1991.
